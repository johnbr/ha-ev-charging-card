## EV Charging Card

A compact, single-row Lovelace card showing an active EV charging session.

- Animated lightning bolt + shimmering progress bar while charging.
- Metrics overlaid on the bar: SoC %, kW, kWh added, ETA to complete.
- Charge-limit marker on the bar.
- Dynamic title — distinguishes home AC charging, Tesla Supercharging, and other DC fast charging via a user-configured entity.
- Integration-agnostic: pass any entities you have (Tesla, Nissan, OpenEVSE, helpers).

Visual configuration via the Lovelace card editor.
